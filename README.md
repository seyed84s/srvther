# Srvther

**شبکه خصوصی امن با تونل زنجیره‌ای Aether**

اپلیکیشن اندروید برای اتصال امن به اینترنت از طریق پروتکل VLESS با تونل زنجیره‌ای Aether. بدون تنظیمات پیچیده — کانفیگ رو اضافه کن و وصل شو.

---

## ✨ ویژگی‌ها

- 🔗 **تونل زنجیره‌ای Aether** — ترافیک VLESS شما اول از تونل Aether (Cloudflare WARP) رد میشه و بعد به سرور VLESS وصل میشه. امنیت و پایداری دوبرابر.
- ⚡ **پشتیبانی کامل VLESS** — پشتیبانی از VLESS, VMess, Shadowsocks, Trojan, WireGuard و Hysteria2 با هسته Xray-core.
- 🛡️ **سه حالت Aether** — MASQUE (HTTP/3 QUIC), WireGuard (تونل مستقیم), WARP×2 (دوبل هاپ ضد فیلترینگ).
- 📋 **ورود آسان کانفیگ** — با کپی/پیست، اسکن QR Code، یا لینک سابسکریپشن.
- 🌗 **طراحی Glassmorphic** — تم تاریک Navy/Mint با افکت‌های شیشه‌ای مدرن.
- 📊 **تست سرعت سرورها** — بررسی پینگ و لیتنسی تمام سرورها با یک ضربه.
- 🔀 **روتینگ هوشمند** — پشتیبانی از قوانین مسیریابی، DNS اختصاصی و Split Tunneling.
- 📱 **Quick Settings Tile** — اتصال/قطع سریع از نوار اعلان.

## 🔗 روال اتصال

```
کاربر → Aether Engine (SOCKS5 :1819) → Xray (VLESS/VMess) → سرور
```

1. دکمه‌ی اتصال زده میشه
2. موتور Aether (Rust) بالا میاد و یک پروکسی SOCKS5 روی 127.0.0.1:1819 باز میکنه
3. Xray-core با کانفیگ VLESS کاربر شروع میشه و ترافیکش رو از طریق Aether رد میکنه
4. نتیجه: ترافیک دوبار رمزنگاری شده و مقاوم در برابر فیلترینگ

## 📥 نصب

1. آخرین نسخه‌ی APK را از بخش [Releases](../../releases) دانلود کنید.
2. فایل دانلودشده را باز کنید تا نصب شروع شود.
3. اگر پیام «Play Protect» دیدید، روی **Install anyway** بزنید.

## 🚀 شروع به کار

1. برنامه را باز کنید.
2. کانفیگ VLESS خودتان را اضافه کنید (از منوی + بالای صفحه، یا کپی لینک، یا اسکن QR Code).
3. سرور دلخواه را انتخاب کنید.
4. دکمه‌ی اتصال را بزنید.
